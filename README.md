# Seattle ADU Permit Readiness Checker (MVP)

A simple rules-based screening tool to help Seattle homeowners understand whether an ADU project is likely, possible, or unlikely based on high-level criteria.

This tool is informational only and is not a permit determination or legal advice.

## Phase 1 Scope
- One city (Seattle)
- Simple form input
- Rules-driven evaluation
- Plain English results
